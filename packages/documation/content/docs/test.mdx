This page is a starter article for onboarding developers. Replace the package name and endpoint with your product details.

## Install

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab value="npm">

```bash
npm install @example/sdk
```

  </Tab>
  <Tab value="pnpm">

```bash
pnpm add @example/sdk
```

  </Tab>
  <Tab value="yarn">

```bash
yarn add @example/sdk
```

  </Tab>
</Tabs>

<Callout type="info" title="Use environment variables">
  Store API keys outside source control and load them through your deployment environment.
</Callout>

## Make the first request

<Steps>
  <Step>
    ### Create an API key

    Generate a key from your dashboard and grant the minimum permissions required for the integration.
  </Step>
  <Step>
    ### Set the key locally

```bash
EXAMPLE_API_KEY=sk_test_123
```

  </Step>
  <Step>
    ### Call the API

```ts
import { ExampleClient } from '@example/sdk';

const client = new ExampleClient({
  apiKey: process.env.EXAMPLE_API_KEY,
});

const projects = await client.projects.list();
```

  </Step>
</Steps>
