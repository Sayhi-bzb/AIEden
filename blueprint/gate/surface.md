# surface

Surface is the return boundary.

Surface receives universe projection or action outcome.

Surface returns organism-facing perception.

## rules

```text
surface keeps return tied to binding
surface preserves accepted/rejected outcome
surface exposes world-safe text
surface does_not_create universe truth
surface does_not_create event
surface does_not_create access
surface does_not_store memory
surface does_not_explain meaning
surface does_not_expose backend
```

## flow

```text
universe Projection
  -> surface
  -> organism PerceptionFrame

action outcome
  -> surface
  -> organism PerceptionFrame
```
