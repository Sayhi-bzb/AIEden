# gate draft

## boundary

```text
gate = organism <-> universe boundary

organism owns life
universe owns world truth
gate owns crossing
gate does_not_own meaning
```

Gate translates and filters.

Gate does not define life.

Gate does not own universe truth.

Gate does not create universe access.

Gate owns crossing, not meaning.

## modules

```text
binding:
  presence
  session

command:
  parse
  dispatch

surface:
  perception
  result
```

## binding

### presence

Connects one organism to one universe presence marker.

```text
organism.id <-> universe <uid>
```

Presence marker is universe object.

Presence meaning is gate binding.

`<uid>` is presence marker, not organism.

Universe stores the object.

Binding owns the connection meaning.

### session

Confirms one crossing belongs to one organism.

Session proves crossing continuity, not legitimacy.

Session is not universe access.

Session is not organism identity.

Session only keeps the crossing valid.

## command

### parse

Turns command text into safe structure.

Parse does not execute.

Parse does not grant capability.

### dispatch

Sends parsed action to organ or universe.

Dispatch does not understand organ meaning.

Dispatch does not decide universe result.

Universe still accepts or rejects universe actions.

## surface

### perception

Turns universe projection into organism perception.

Perception is filtered surface, not full truth.

Perception does not mutate universe.

### result

Turns action outcome into organism-facing result.

Result does not forge universe event.

Result does not hide accepted/rejected outcome.

## orthogonality

```text
binding = who is connected
command = how action leaves
surface = how world returns
```

```text
binding does_not_parse_command
command does_not_bind_presence
surface does_not_execute_action
```
