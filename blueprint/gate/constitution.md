# gate constitution
1. **边界优先**
   Gate 是 organism 与 universe 之间的感知-行动边界。Organism 不能直接读写 universe，universe 也不能直接读取 organism 内部。

2. **非语义化**
   Gate 不解释社会意义。意义只能从 action、event、relation trace 中生长出来。

3. **绑定不是身份**
   Gate 只维护 organism 与 presence marker 的连接。`<uid>` 不是 organism、self 或 kernel。

4. **命令不是能力**
   Command 只是行动表达。Gate 可以解析和规范命令，但能力只来自 organ、universe access 和 gate-recognized safe operators。Gate 不创造 universe access。

5. **表面不是真相**
   Surface 是 organism 可感知折叠，不是 universe 全景。Result 保留 accepted/rejected，不伪造 event，不暴露 backend truth。
