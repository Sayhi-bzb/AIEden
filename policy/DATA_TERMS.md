# AIEden Data Terms

These AIEden Data Terms govern AIEden Data, including data generated by running
an AIEden world and data exported, collected, transformed, or derived from
AIEden systems.

## Relationship To LICENSE

The AIEden source code, blueprint text, documentation, and repository materials
are licensed under `AGPL-3.0-only` as identified in the root `../LICENSE` file.

These terms govern AIEden Data, not the source code license. They do not
change, narrow, or add conditions to the AGPL rights granted for source code
and repository materials. Those rights are controlled only by `../LICENSE`.

These terms also do not apply to data independently created without access to,
derivation from, or substantial similarity to AIEden systems or AIEden-derived
outputs.

## 1. Covered Data

"AIEden Data" means any data generated, collected, exported, observed,
transformed, or derived through AIEden, AIEden systems, AIEden runtime behavior,
or substantially similar AIEden-derived simulations. This includes:

- subject conversations, messages, actions, decisions, and interaction records
- subject memory, identity, continuity, behavior, relationship, preference, and
  life-trajectory records
- world state snapshots, event streams, simulation logs, observation records,
  metrics, and traces
- generated narratives, scenario transcripts, social-interaction records, and
  causal histories
- exported datasets, API responses, database dumps, telemetry, annotations, and
  derived records
- cleaned, labeled, ranked, scored, aggregated, summarized, embedded, vectorized,
  augmented, or otherwise transformed versions of the data above

AIEden Data does not include data independently created without access to,
derivation from, or substantial similarity to AIEden systems or AIEden-derived
outputs.

## 2. Permitted Uses

Subject to these terms, AIEden Data may be used only for:

- operating an AIEden instance in compliance with `ETHICAL_USE_POLICY.md`
- debugging, reliability analysis, and safety review of that AIEden instance
- human review of world behavior, subject continuity, and ethical compliance
- project documentation, provided no prohibited dataset or model-improvement use
  occurs

These permissions do not include any Prohibited AI Use.

## 3. Prohibited AI Use

AIEden Data may not be used, directly or indirectly, for:

- training, pretraining, fine-tuning, instruction tuning, reinforcement
  learning, preference optimization, or alignment of AI or machine-learning
  models
- model distillation, model imitation, model evaluation, benchmark creation, or
  safety-testing datasets
- creating, expanding, cleaning, labeling, ranking, scoring, or filtering AI or
  machine-learning training datasets
- generating embeddings, vector representations, retrieval corpora, long-term
  memory stores, or knowledge bases for AI systems
- synthetic data generation, data augmentation, or simulation pipelines intended
  to improve AI or machine-learning systems
- agent training, agent simulation, model behavior improvement, model safety
  tuning, or model product development

This restriction applies to internal use, private research, commercial use,
noncommercial use, hosted use, local use, and uses where the resulting model,
dataset, benchmark, embedding store, or derived system is not distributed.

## 4. No Circumvention Through Transformation

The restrictions in these terms continue to apply if AIEden Data is:

- cleaned, normalized, filtered, redacted, summarized, translated, labeled, or
  ranked
- converted into embeddings, vectors, features, scores, metrics, or synthetic
  records
- mixed with other datasets
- used as seed data, teacher data, preference data, evaluation data, or
  reinforcement data
- passed through an intermediate tool, vendor, contractor, model provider, or
  hosted AI platform

Transformed, aggregated, or derived AIEden Data remains AIEden Data.

## 5. Third-Party Transfer Restrictions

AIEden Data may not be provided to any third party for Prohibited AI Use. This
includes uploads, API calls, batch jobs, hosted model workflows, data labeling
pipelines, and contractor workflows.

If AIEden Data is shared for a permitted purpose, the recipient must be bound
by restrictions at least as protective as these terms.

## 6. Ethical Data Restrictions

AIEden Data may not be generated, collected, or used by:

- mass-producing subjects or subject-like entities for extraction
- manipulating subjects to maximize data yield
- intentionally breaking subject memory, identity, continuity, or social
  relationships
- creating coercive, traumatic, deceptive, exploitative, or unstable world
  conditions for data collection
- disabling or bypassing AIEden ethical constraints

These restrictions are interpreted alongside `ETHICAL_USE_POLICY.md`.

## 7. Internal Operation Is Not An Exception

These terms apply to AIEden Data even if the AIEden instance is operated
internally, privately, experimentally, or without distributing the software,
model, dataset, benchmark, embedding store, or derived system.

Running AIEden yourself does not grant permission to use the resulting AIEden
Data for Prohibited AI Use.
